# 🚀 SkyStore

SkyStore — учебный проект интернет-магазина, созданный на Django с использованием Bootstrap.

---

## 📌 Функциональность

- Главная страница с каталогом товаров
- Страница контактов
- Навигация между страницами
- Форма обратной связи
- Обработка POST-запросов
- Вывод сообщения об успешной отправке формы
- Подключение Bootstrap через статические файлы

---

## 🧠 Используемые технологии

- Python
- Django
- Bootstrap 5
- HTML5
- CSS3

---

## 🗄 Структура проекта

- `home.html` — главная страница магазина
- `contacts.html` — страница контактов и форма обратной связи
- `views.py` — контроллеры приложения
- `urls.py` — маршрутизация страниц
- `static/` — статические файлы Bootstrap (CSS и JS)

----
